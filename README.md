# PIPOS

Personal Investment Portfolio Optimisation Script (PIPOS)

## About

A script that uses market data from yfinance with H. Markowitz's modern portfolio theory to optimize the selected ticker portfolio.

## Launching

Currently you need to have yfinance in your env for it to work.

If you have yfinance in your env then just do in the src folder:

```
python3.14 main.py
```

## Purpose

Making this project to have a way to actually use mathematics in my day to day life.
